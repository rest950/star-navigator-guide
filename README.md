## 📖 專案簡介

麗星郵輪探索星號的 **Mobile-First 單頁導覽（PWA）**，架構沿用姊妹專案 [Costa Serena 莎倫娜號導覽](https://github.com/rest950/costa-serena-guide)，並加上針對單一航次的行程攻略。加到主畫面後可**完全離線使用**——船上網路要付費、外海常斷線也照樣能查。

## ✨ 功能

* 🗓️ **航程攻略（首頁）**：登船倒數、船上／日本雙時鐘、Day 1–6 每日安排（今天自動展開）、行前清單（勾選存在手機）、船上實用資訊。
* ⚓ **港口攻略**：神戶（夜間停靠 15:00–01:00）與高知（11:00–20:00）的碼頭交通、入境節奏、景點時間、美食、免稅新制，各 3 條路線提案。
* ⏰ **回船倒數**：輸入郵報公布的最晚回船時間，靠港當天自動倒數，並換算船上時間。
* 🚢 **全船速覽**：Deck 13 → 4 剖面，「依需求直達」快捷卡（免費用餐、看秀、親子…）。
* 🏛️ **單一 Deck**：左右滑動換層，每項設施有位置、免費／付費、小提醒。
* 🔍 **全船搜尋**、⭐ **收藏**、🍽️ **餐飲速查**（由設施資料自動產生）、🧭 **防迷路指南**。
* 🔗 **可分享網址**：`#/`（行程）、`#/ship`、`#/deck/7`、`#/port/kobe`、`#/starred`。
